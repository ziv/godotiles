# How to contribute

Thanks for your interest! Bugs, feature requests and patches are welcome via
[GitHub issues](https://github.com/ziv/godotiles/issues) and pull requests.

## Development environment

- Rust stable (1.85+)
- Godot 4.7.x (editor for the demo, headless binary for the smoke test)

```sh
cd rust && cargo test            # core + source tests (offline)
./scripts/build.sh release       # build the extension into addons/godotiles/bin/<platform>/
godot --path . demo/main.tscn    # run the demo
```

## Conventions

- Conventional Commits (`feat:`, `fix:`, `feat!:`) — versions and the changelog are generated by
  release-please.
- `cargo fmt` and `cargo clippy --all-targets -- -D warnings` must be clean.
- `rust/src/core/` must never import `godot::` — it is the engine-agnostic core.
